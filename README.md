# Licença Casa Hacker

Adaptação da [MIT License](https://opensource.org/licenses/MIT) para a jurisdição brasileira, desenvolvida pela [Casa Hacker](https://casahacker.org).

## O que é

A Licença Casa Hacker mantém a permissividade da MIT License — uso livre, modificação, distribuição, sublicenciamento e venda — acrescentando cláusulas que refletem o ordenamento jurídico brasileiro:

| Cláusula | Base legal |
|---|---|
| Direitos morais inalienáveis | Lei n.º 9.610/1998, art. 27 (LDA) |
| Limitação de responsabilidade | CC/2002, arts. 186 e 927 |
| Proteção de dados pessoais | Lei n.º 13.709/2018 (LGPD) |
| Conformidade anticorrupção e lavagem | Leis n.º 12.846/2013 e 9.613/1998 |
| Força maior | CC/2002, art. 393 |
| Foro: São Paulo/SP | Eleição contratual |

## Como usar em seu projeto

1. Copie o arquivo [`LICENSE`](LICENSE) para a raiz do seu repositório.
2. Substitua `2026 Casa Hacker` pelo ano corrente e pelo nome do seu projeto ou organização:

```
Copyright (c) <ANO> <SEU NOME OU ORGANIZAÇÃO>
```

3. Opcionalmente, adicione ao seu `README.md`:

```markdown
Licenciado sob a [Licença Casa Hacker](https://github.com/casahacker/licenca/blob/main/LICENSE).
```

## Compatibilidade

A Licença Casa Hacker é **compatível com a MIT License** no que se refere às quatro liberdades essenciais (uso, cópia, modificação e distribuição). As cláusulas adicionais são declaratórias do direito brasileiro vigente e não restringem essas liberdades.
